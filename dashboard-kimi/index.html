Scoring methodology

  • pre-market call on day D is judged against the regular session: open(D) → close(D).
  • intraday call on day D is judged against the overnight gap: close(D) → open(next trading day).
  • HOLD is correct when the session rises; SELL is correct when it drops. Exactly flat = incorrect, 0 pts.
  • Weighted score = ±|session return %| per call — a correct call before a 2% move earns 4× a 0.5% move; wrong calls deduct the same magnitude.
  • Duplicate runs are deduped per (engine, date, session), keeping the latest file. Calls whose outcome hasn't happened yet are pending and excluded from stats.

Data sources

  • Predictions: read live from input/ in this repo via the GitHub API on every page load — push new files, hit refresh.
  • Prices: QQQ daily OHLC + 30-min bars (incl. pre/post market) from Yahoo Finance, via a CORS fallback chain.
  • Optional: drop input/qqq-prices.json in the repo to serve prices straight from GitHub Pages (format: {"daily":[{"date","open","high","low","close"}…]}).

Caveats

  • Signals are HOLD/SELL only — this measures defensive timing, not long-entry skill.
  • Engines differ in coverage (missing dates are not penalized; accuracy is over scored calls only).
  • crash-live placeholder stubs ("No open catalysts.") are excluded unless toggled on.
